Socialchoice System Architecture

Core State & Isolation

Four SQLite-backed Durable Objects (WORKSPACE, CUSTOMER_DIRECTORY, CUSTOMER_WORKSPACES, AI_EGRESS) provide per-tenant storage and US AI egress without external DB hops.

Edge Proxy & Auth Safety

Vercel serves the Vite SPA on socialchoice.site and proxies /api/*, /s/*, and /mcp with Cache-Control: no-store. AuthContext runs once on mount; non-JSON edge errors are sanitized.

Offline Desktop & Async

Tauri desktop falls back to local SQLite (:3002) and auth-broker. Production autopilot jobs run through Cloudflare Queues (8 retries + DLQ) with R2 asset storage.
