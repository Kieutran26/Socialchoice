# Composer preview

Create Post uses 30/70 editor/preview on wide screens and stacks below 800px available canvas. Facebook-style preview includes selected Page name, expandable caption, ordered image mosaics, image inspection and video playback. Facebook controls final cropping/layout; no engagement metrics are fabricated.

Facebook collaboration was removed at owner request on 2026-10-13 after an approved real test invitation was rejected. Collaboration API returns410 after authentication. Private attempt history is retained. No invitation success or recipient acceptance is claimed. Normal text/photo/video Publish Now remains available.

Select accounts from Facebook, Instagram, Threads, TikTok and LinkedIn within one brand. Main caption is the default; Captions by platform supplies optional shared overrides for all accounts of a platform; Per-account content and schedule supplies the highest-priority account override. Empty/whitespace-only overrides inherit. Draft save, edit and duplicate preserve platform/account captions. Preview and server approval resolve the same exact caption, including retained whitespace in nonempty overrides. Preview account identifies both account and platform and shows its effective local schedule/timezone.

Channel checks lists caption length and content/connection issues for each selected account before review. It follows the implemented adapters: Instagram one JPEG or MP4, Threads text/one JPEG/MP4, LinkedIn text/JPEG/PNG/one MP4 up to30 MiB, TikTok one MP4 plus explicit sandbox choices, and Facebook text/up to ten images/one MP4. Instagram images also require the supported aspect ratio. TikTok checks use the loaded creator duration limit and interaction permissions; refresh failure blocks review. Media is shared: choose a format valid for every destination, or deselect incompatible accounts. Checks do not prove private grants, token validity, future creator limits or provider acceptance; the server rechecks these during review and delivery. Drafts may retain incomplete content. Schedule checks each effective account time at least one minute ahead, stored as UTC.

Publish now or Schedule saves the draft and opens one review showing every account/platform, caption, shared media and (for scheduling) exact time. Review alone makes no publishing request. Confirmation validates every destination atomically before queuing one independent attempt per account; provider IDs are qualified by platform. A failure or cancellation does not resend another destination. Post details shows Results by account with separate outcomes, links when confirmed, cancellation and reviewed failed-only retries. Existing single-account and Facebook multi-Page operations remain supported. Unconfirmed writes are never resent automatically.

Verification: mixed five-platform video approvals, content/identity rejection, replay/cancellation and isolated failures pass local tests. Fixture credentials/data are synthetic; provider requests are blocked. This feature has not been deployed or verified with live cross-platform publishing.

Selected images can be dragged onto another image to reorder. The grip supports pointer/touch input; arrow buttons provide keyboard reordering. Preview and publication use the resulting media order. Video playback remains interactive.
