# Composer preview

Create Post uses 30/70 editor/preview on wide screens and stacks below 800px available canvas. Facebook-style preview includes selected Page name, expandable caption, ordered image mosaics, image inspection and video playback. Facebook controls final cropping/layout; no engagement metrics are fabricated.

Facebook collaboration was removed at owner request on 2026-10-13 after an approved real test invitation was rejected. Collaboration API returns410 after authentication. Private attempt history is retained. No invitation success or recipient acceptance is claimed. Normal text/photo/video Publish Now remains available.

Select accounts from Facebook, Instagram, Threads, TikTok and LinkedIn within one brand. Main caption is the default; Captions by platform supplies optional shared overrides for all accounts of a platform; Per-account content and schedule supplies the highest-priority account override. Empty/whitespace-only overrides inherit. Draft save, edit and duplicate preserve platform/account captions. Preview and server approval resolve the same exact caption, including retained whitespace in nonempty overrides. Preview account identifies both account and platform and shows its effective local schedule/timezone.

Channel checks lists caption length and content/connection issues for each selected account before review. It follows the implemented adapters: Instagram one JPEG or MP4, Threads text/one JPEG/MP4, LinkedIn text/JPEG/PNG/one MP4 up to30 MiB, TikTok one MP4 plus explicit sandbox choices, and Facebook text/up to ten images/one MP4. Instagram images also require the supported aspect ratio. TikTok checks use the loaded creator duration limit and interaction permissions; refresh failure blocks review. Shared media is the default. Media by platform lets each selected platform override it with an ordered private asset list; all accounts of that platform use that list. Uncheck the override to inherit shared media again. An empty enabled override means text-only, and channels requiring media show a blocking issue. Selecting/changing brands clears every media selection; deselecting a platform preserves its override for later reuse. No per-account media override or transcoding is added. Checks do not prove private grants, token validity, future creator limits or provider acceptance; the server rechecks these during review and delivery. Drafts may retain incomplete content. Schedule checks each effective account time at least one minute ahead, stored as UTC.

Publish now or Schedule saves the draft and opens one review showing every account/platform, caption, effective platform media (or explicit No media) and (for scheduling) exact time. Review alone makes no publishing request. Confirmation validates every destination atomically before queuing one independent attempt per account; provider IDs are qualified by platform. A failure or cancellation does not resend another destination. Post details shows Results by account with separate outcomes, links when confirmed, cancellation and reviewed failed-only retries. Existing single-account and Facebook multi-Page operations remain supported. Unconfirmed writes are never resent automatically.

Verification: mixed five-platform video approvals, content/identity rejection, replay/cancellation and isolated failures pass local tests. Browser fixture verified caption validation, preview precedence, draft reopen, three-platform text review/scheduling and independent result/cancellation. Fixture credentials/data are synthetic; provider requests are blocked. This feature has not been deployed or verified with live cross-platform publishing.

Selected images can be dragged onto another image to reorder. The grip supports pointer/touch input; arrow buttons provide keyboard reordering. Preview and publication use the resulting media order. Video playback remains interactive.

Platform media verification (2026-10-18): save/edit/duplicate preserve `platform_media_ids`, including explicit empty lists; absent keys inherit `media_ids`. References stay within the brand/demo scope and protect private assets against deletion. Review/schedule/retry and execution freeze each destination's effective ordered media, invalidate changed approvals and preserve the existing no-resend boundary. Local tests cover mixed Facebook images/Instagram video/Threads text, malformed inputs, stale reviews, replay, queue locks, retry and deletion guards. Isolated browser checks cover per-channel preview, incompatible-format feedback, saving/reopening/duplicating and mobile layout. No live publication or deployment is claimed.

## Reusable post templates

Save as template snapshots the current composer content without saving or changing its source post. A named PostTemplate belongs to one brand/demo workspace. Content includes selected accounts and their nonempty caption overrides, main/platform captions, ordered shared/platform media IDs and pillar/angle. The server accepts content only: schedules, account times, TikTok choices, provider state/IDs and credentials cannot be persisted on a template, including through generic entity APIs.

Content → Post templates provides scoped search/pagination, rename, delete and Use template. Using one creates a fresh Post draft with the brand timezone, no main/account publishing time and no jobs or approvals. There is no schedule execution from a template. Archived pillar/angle references are removed from the new draft with a visible warning; the template stays unchanged. An archived brand is rejected. Existing drafts stay independent after template rename/deletion.

All account, strategy and media references are checked against the template brand/demo scope. Template-only shared/platform media references prevent deletion in the server and are counted in Media Library. Brand, pillar, angle and account delete dialogs recheck template usage and show a current template count with guidance to remove templates or archive/disconnect instead. Templates referencing incomplete channel content can be saved; the normal composer/channel validation still gates publication. To update content, make a draft, edit and save as a new template, then remove the old template if desired. No template scheduling, per-account media overrides or AI generation is added.

Local verification: template persistence across restart, unsaved-content capture, independent repeated draft creation, schedule/consent stripping, invalid/cross-brand/demo references, protected assets, archived strategy warnings and authenticated/origin-checked endpoints. Browser checks cover save, list/search/rename/use twice, blank main/account times, retained media/captions/strategy,375/768/1440 layouts and deletion preserving drafts. Test data isolated; no provider requests or deployment.

## Inline LinkedIn mentions

When a LinkedIn destination is selected, type `@` in the main caption, reusable template caption, LinkedIn platform/account caption or follow-up comment. Suggestions filter connected live LinkedIn accounts and valid mention tokens already present in that same text. Vietnamese names match with or without accent marks. Choose with Up/Down and Enter or click; Escape closes the suggestions. Selection replaces the typed query at the current caret and preserves the surrounding text. IME composition and email addresses do not trigger insertion.

The existing manual name + organization/member ID control remains available for other entities. A plain `@name` is ordinary text until a real ID-backed mention is chosen. Token storage and LinkedIn publication attributes retain their existing format; preview renders the label. There is no broad LinkedIn people search: LinkedIn's People Typeahead API is restricted and requires organization follower access, which the current personal-profile app does not have. See [official API requirements](https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/posts-atmention-search-api).

Verification: isolated browser fixture confirms Vietnamese matching, Enter and pointer selection, parent draft-state updates and insertion in the middle of a sentence without losing the suffix. Pure contract tests cover selections, emails, stored tokens, invalid IDs and the publishing parser. No live LinkedIn publication is used for these checks.

Company lookup: type `@microsoft`, then choose **Find LinkedIn company** and insert the returned company. The expanded mention bar also accepts an exact company vanity name or `https://www.linkedin.com/company/name` link. With multiple connected LinkedIn accounts, choose the account whose authorization is used for lookup. This is an explicit exact-name lookup, not global people search or fuzzy company-name search. The backend obtains the real organization ID from LinkedIn; a permission refusal is shown as an error, not an empty result. Existing manual ID entry remains available. Live lookup depends on the application's approved LinkedIn organization API access; the basic personal-profile publishing grant alone does not establish that access.
