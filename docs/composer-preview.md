# Composer preview

Create Post uses 30/70 editor/preview on wide screens and stacks below 800px available canvas. Facebook-style preview includes selected Page name, expandable caption, ordered image mosaics, image inspection and video playback. Facebook controls final cropping/layout; no engagement metrics are fabricated.

Private attempt history is retained. No invitation success or recipient acceptance is claimed. Normal text/photo/video Publish Now remains available.
